# Rudrayan Dey Portfolio

Plain HTML + CSS + JavaScript portfolio.

## Files
- `index.html` — page content and structure
- `style.css` — responsive dark theme and layout
- `script.js` — mobile menu, active navigation, reveal animations and back-to-top button
- `assets/` — optional folder for a resume, profile image, or other assets

## Important placeholders
The portfolio intentionally contains:
- 2 placeholder experience entries in the Experience section
- 1 placeholder project in the Projects section

Replace those sections directly in `index.html` when the information is ready.

## Resume
No resume download button has been added because the supplied CV was used as the source for the portfolio content. If a downloadable resume is wanted later, place the PDF inside `assets/` and add a button linking to it.

## Hosting
This is a static website and can be hosted directly with GitHub Pages, Netlify, Vercel, or any static hosting service.
